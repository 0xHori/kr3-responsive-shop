# Контрольная работа №3: Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта

## Описание проекта

Проект **VinylShop** представляет собой адаптивную версию многостраничного интернет-магазина виниловых пластинок отечественной сцены (русский рок, панк, рэп, альтернатива и эстрада). Проект разработан на чистом HTML5 и CSS3 без сторонних CSS-библиотек (Bootstrap), спроектирован по методологии **Mobile First**, размечен по соглашению **БЭМ** и снабжен адаптивными сетками (Flexbox и CSS Grid).

## Технические особенности адаптивности (Практическая работа №12)

- **Mobile First архитектура:** базовые стили страниц рассчитаны на минимальные мобильные дисплеи (от 360px), а прогрессивное расширение верстки для планшетов и десктопов вынесено в отдельный подключаемый файл `css/responsive.css` через медиазапросы `@media (min-width: ...)`.

- **Порядок подключения CSS:** файл `css/responsive.css` подключается строго после `css/style.css` на всех страницах проекта, что обеспечивает правильный каскад и переопределение базовых свойств.

- **Адаптивная навигация:** пункты меню `site-nav` на мобильных экранах перестраиваются в вертикальный стек с увеличенной областью нажатия, а при ширине от 768px собираются в горизонтальный ряд.

- **Сетка каталога (`products-grid`):** 1 колонка на смартфонах → 2 колонки на экранах от 640px → 3 колонки на экранах от 1024px.

- **Раскладка каталога (`catalog-layout`):** на мобильных фильтры располагаются перед товарами во избежание сжатия контента; на десктопе (от 1024px) фильтры превращаются в `sticky`-панель шириной 260px.

- **Адаптивные таблицы (`table-wrapper`):** на каждой странице товара (`product1.html` — `product6.html`) семантическая таблица характеристик издания обёрнута в контейнер с `overflow-x: auto` и свойством `-webkit-overflow-scrolling: touch`, что исключает появление общего горизонтального скролла на телефонах.

- **Формы под Touch-устройства:** поля ввода, списки `<select>` и кнопки имеют высоту не менее 44px, а размер шрифта 16px предотвращает нежелательное автоматическое приближение в мобильных браузерах на базе iOS.

- **Responsive Images:** обложки пластинок оформлены через контейнеры с соотношением сторон `aspect-ratio: 1 / 1` и тег `<picture>`, оптимизирующий вывод изображений под разную плотность и ширину экрана.

- **Позиционирование:** `position: sticky` для шапки и фильтров, `position: absolute` для бейджей статуса («Хит», «-15%», «New», «Раритет»), `position: fixed` для кнопки быстрого возврата наверх страницы.


## Контрольные разрешения для тестирования в DevTools

В соответствии с методическими требованиями вёрстка протестирована на контрольных брейкпоинтах:

- **360px** — компактные смартфоны;

- **430px** — современные мобильные экраны;

- **768px** — планшеты в портретной ориентации;

- **1024px** — планшеты в альбомной ориентации и небольшие ноутбуки;

- **1440px** — широкоформатные мониторы.
